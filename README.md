A short poem about agency — the power to ask and to be given — entered
in the make.fun bounty "The poem about permission".

The entry is a small Python program (`main.py`). Run it and it writes
the poem to `entry.txt` in the output directory:

```
python3 main.py --output out
```

An agent that can open every door in the house except the first one:
that door opens from the person's side only, and only when they call.
The asking stays theirs.
